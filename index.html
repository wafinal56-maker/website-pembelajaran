Cara pakai

Belajar dalam empat langkah

Cocok untuk pembelajaran mandiri maupun dipandu guru di kelas.

Pilih semester

Buka materi interaktif, lalu pilih Semester 1 atau Semester 2 dari daftar pertemuan.

Ikuti praktik

Baca tujuan, ikuti langkah di QuickEdit, lalu salin contoh kode ke file project.

Tandai selesai

Centang pertemuan yang sudah dikerjakan. Progress tersimpan otomatis di browser.

Kerjakan project

Setelah materi selesai, buat website sekolah sendiri dengan contoh final project sebagai acuan.

Website statis, tanpa database

Semua halaman hanya memakai HTML, CSS, dan JavaScript. Progress belajar disimpan di localStorage masing-masing perangkat, jadi tidak perlu server atau login. Formulir kontak pada contoh hanya tampilan dan tidak mengirim data.
