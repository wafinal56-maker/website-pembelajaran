SMK CREATIVE HUB — FINAL PROJECT HTML & CSS
Cara menjalankan:
1. Ekstrak folder final-project.
2. Buka folder tersebut di QuickEdit.
3. Buka index.html, lalu pilih Preview/Open in Browser.
4. Pastikan folder css dan images tetap berada di lokasi yang sama.
5. Ganti gambar contoh images/sekolah.jpg dengan foto yang sesuai (nama file harus sama).

Catatan:
- Semua halaman adalah website statis HTML dan CSS.
- Formulir kontak hanya tampilan dan belum mengirim data ke server.
- Gambar sekolah.jpg adalah placeholder; ganti dengan gambar milik sendiri yang memiliki izin.
- Edit data profil, jurusan, kegiatan, dan kontak sesuai kebutuhan sekolah.
