HASIL SEMESTER 1 (VERSI 1.0)
============================

Folder ini adalah contoh website yang dihasilkan setelah menyelesaikan
Pertemuan 1 sampai 18 (Semester 1).

Isinya:
- 7 halaman: index, profil, jurusan, kegiatan, galeri, portofolio, kontak
- Struktur HTML semantik: header, nav, main, section, footer
- CSS dasar: variabel warna, tipografi, box model, border, shadow, tombol
- Tampilan masih sederhana: navigasi belum memakai Flexbox, kartu belum
  memakai Grid, dan halaman belum memakai media query.

Cara membuka:
1. Buka file index.html di browser, atau
2. Buka lewat website materi: Pertemuan 18 -> "Lihat hasil Semester 1".

Catatan:
- Jangan membandingkan folder ini dengan final-project/. final-project/
  adalah hasil akhir Semester 2 (versi 2.0) setelah materi Flexbox, Grid,
  media query, animasi, dan aksesibilitas.
- Folder ini sengaja dibuat sederhana agar sama dengan hasil praktik siswa
  pada akhir Semester 1.
